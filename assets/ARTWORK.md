# Original PWA artwork

Generated with the built-in image-generation tool. Final assets are bundled here, converted to WebP for delivery; creature/prop transparency is preserved. No runtime image service or native project dependency is used.

| Asset | Final prompt / art direction |
| --- | --- |
| `forest.webp` | Tall portrait cinematic fantasy forest sanctuary, mossy ancient arches, layered emerald ferns, golden volumetric sunlight, open central stone path. Detailed tactile 3D environment; no text, characters, UI, or logo. |
| `neon.webp` | Tall portrait futuristic neon district, hanging gardens, magenta/cyan lamps, wet stone reflections, central causeway toward a luminous gate. Same premium cinematic art direction; no lettering, characters, or UI. |
| `ocean.webp` | Tall portrait underwater coral kingdom, turquoise water, peach/lilac coral, shell arches and sunbeams, open pale central causeway. No characters, text, or UI. |
| `creatures.webp` | Transparent square 3 × 3 front-view atlas, three original evolution lines: leaf fox → antlered forest guardian; electric fox → storm mane; aquatic otter-dragon → pearl-crowned tide guardian. Soft detailed 3D rendering, glossy friendly eyes, complete silhouettes. Final edit reduces each sprite to 70%, centers it in its equal grid cell, and leaves clear gutters around all appendages. |
| `runners.webp` | The same exact nine designs, directly from behind, poised to run away from the camera. Same transparent 3 × 3 atlas and clear-gutter edit. No faces looking back, labels, or scenery. |
| `props.webp` | Transparent square 3 × 3 production obstacle atlas, equal cells with clear gutters. Forest row: mossy boulder, low stone beam gate with a slide opening, fern-topped carved pedestal. Neon row: violet-lit barricade, cyan/magenta low beam gate, luminous pillar. Ocean row: coral-covered ivory rock, shell-carved low beam arch, peach/lilac coral cluster. Slightly elevated front-facing 3D game camera, detailed cinematic materials, complete silhouettes. No characters, labels, grid lines, UI, or background. |

The root `icon-192.png` and `icon-512.png` use generated art: a close-up of the original moss-green baby fox, cream muzzle, large glossy green eyes, leafy sprout, warm forest light, opaque square background, no lettering or baked rounded corners.

World and creature source generation IDs are recorded in the archived experiment's `Design/ARTWORK.md`. The prop atlas source is `exec-ac84074f-fb91-416d-9e41-691369f77280.png`. Audio is synthesized locally in Web Audio. Interface icons are project-local SVG geometry.
